# MRO Price Scout

AI-powered price comparison for MRO procurement. Upload your SAP / Ariba export and the tool benchmarks each line item against major industrial suppliers.

## Run locally

    npm install
        npm start

        ## Deploy on Vercel
        1. Push this repo to GitHub
        2. Import on vercel.com
        3. Add env var REACT_APP_ANTHROPIC_API_KEY (get key at console.anthropic.com)
        4. Deploy
